# 晚安瑜伽 · Night Yoga

睡前 5 到 15 分鐘的溫和伸展、核心與呼吸引導網頁。免註冊、無廣告、支援離線使用（PWA）。

- **主站（Netlify）**：<https://night-yoga.netlify.app/>
- **備站（GitHub Pages）**：<https://cornming.github.io/night-yoga/>
- **匿名完成統計**：<https://cornming.github.io/stats/>

## 功能特色

- **依今晚狀態選課**：提供全程躺著做（做完直接睡）、坐姿伸展，以及專為孕期設計的「坐著與側躺」舒緩課程。
- **呼吸引導**：內建 4-7-8 呼吸、延長吐氣與方塊呼吸，搭配視覺圓圈縮放與語音節奏。
- **自然語音與即時合成環境音**：體式口訣、動作中提醒、換邊與倒數語音引導；水晶鋼琴、頌缽、溫暖長音、雨聲、海浪皆由瀏覽器即時合成。
- **貼心練習體驗**：支援螢幕常亮（Wake Lock）、鎖屏與藍牙耳機控制（MediaSession）、畫面亮度調整、連續練習紀錄與每日行事曆提醒（`.ics` / Google 日曆）。

## 安全提醒

本網站內容僅為一般睡前放鬆與溫和伸展，不能取代專業醫療建議。練習過程中若有任何疼痛或不適請立即停止；如有傷病或懷孕，請先諮詢醫師。
