# night-yoga

一系列在床上做的睡前瑜珈課程。**全程躺著**，不用跪、坐或站起來，做完就能直接睡。

動作是從網路上找到的文章整理出來的，每個動作都標了來源；沒有來源的內容，不會寫進課程裡。

## 課程總覽

| 課 | 主題 | 時長 | 用到的動作 |
|---|---|---|---|
| [01](lessons/01-lie-down.md) | 躺好就好 | 8 分鐘 | 攤屍式、仰臥束角式 |
| [02](lessons/02-hips.md) | 放鬆髖部 | 12 分鐘 | 抱膝、快樂嬰兒、左右倒膝、束角 |
| [03](lessons/03-twist.md) | 溫柔扭轉 | 12 分鐘 | 抱枕支撐的仰臥扭轉 |
| [04](lessons/04-legs.md) | 腿與臀 | 12 分鐘 | 仰臥伸腿、抱腿壓胸、小腿靠枕 |
| [05](lessons/05-side-lying.md) | 側臥入睡 | 10 分鐘 | 側臥伸展、側臥攤屍式 |
| [06](lessons/06-chest-shoulders.md) | 胸口與肩膀 | 10 分鐘 | 枕頭支撐魚式、扭轉開胸（選配：趴姿擴胸） |
| [07](lessons/07-full-routine.md) | 完整睡前流程 | 15 分鐘 | 串起前面的動作 |

建議從課程 01 開始。每堂課獨立，也可以只挑當天想做的那一堂。

## 準備

- 2～4 顆枕頭、一條毯子（想蓋的話）。
- 課程文字裡的「呼吸時間」，是以一次呼吸約 6 秒估算，僅供規劃，以你自己的節奏為準。
- 床墊很軟的話，動作幅度放小。伸展感不明顯沒關係，這個系列的目的是放鬆，不是拉筋。

## 安全

- 任何地方出現**刺痛、發麻，或越做越不舒服，就停下來**，回到攤屍式。
- 動作應該是溫和的伸展，不要用力硬做。
- 懷孕、年長，或有健康狀況的人，請先和醫療人員討論，有些姿勢可能需要調整或避開（NIH 的 NCCIH 也是這樣建議）。

## 這個系列不是什麼

這是睡前的放鬆習慣，**不是失眠的治療**。

瑜珈對睡眠的研究，測的是持續數週、每次 45～120 分鐘的完整課程，這個系列每堂只有 8～15 分鐘，**不能直接套用那些研究的結果**。美國退伍軍人事務部與國防部 2019 年的指引也表示，證據不足以建議或反對用瑜珈治療失眠。長期失眠請就醫。

細節與出處見 [docs/research.md](docs/research.md)。

## 網頁版（課程 01）

躺在床上用手機跟著做：說明頁 → 逐步倒數、動作圖示、呼吸引導圈與語音朗讀 → 完成。深色低亮度。純前端、無建置步驟。

`index.html` 不能直接雙擊開啟（瀏覽器會擋掉部分功能），請用任一靜態伺服器，在這個資料夾內執行：

```bash
python -m http.server 5173
```

再開 http://localhost:5173/

目前只有課程 01 做成網頁，其餘 6 堂還只有 Markdown 文字版。

**線上版**：repo 設定裡把 Pages 指向 `main` 分支的根目錄，網址會是 https://cornming.github.io/night-yoga/（目前尚未啟用，內容也還沒合併到 `main`）。

### 語音朗讀

說明頁的「語音朗讀」預設開啟，播放中也能用「朗讀：開／關」切換，偏好會記在這台裝置。

- 每一步開頭先報「第一步，躺好。」，再依序念口令，句與句之間停 2.5 秒；念完就安靜，讓你自己呼吸。完成時念「做完了。可以直接睡了。」
- 暫停會同時停掉朗讀，繼續時從被打斷的那句重念。「下一步」或計時換步時，會取消目前這句、改念新的那一步。
- 語音的挑選順序：台灣國語（zh-TW）→ 其他繁體中文 → 其他普通話（例如 zh-CN，畫面會註明不是台灣國語）。不使用粵語。
- 找不到中文語音時，開關會停用並說明原因；瀏覽器不支援時整個隱藏。朗讀失敗（例如被瀏覽器拒絕）會顯示原因並自動關閉，計時照常進行。
- 朗讀的文字就是口令稿本身，沒有另外加內容。

### 動作圖示

每一步旁邊有一張示意圖：從上方看躺在床上的人，頭在左、腳在右，床上有一顆枕頭。它是依關節角度算出來的簡單剪影，用來幫你確認姿勢的大致形狀，**不是真人示範，也不能取代文字說明**。

- 畫的內容只依 [poses.md](poses.md) 的描述：攤屍式是雙臂在身體兩側、雙腿伸直；仰臥束角式是腳掌相對、兩膝向兩側打開。
- 目前只有 P01、P02。其餘動作有的是側臥、趴姿或扭轉，同一個俯視角度不一定看得清楚，加之前要先決定怎麼畫，才不會畫出不準確的姿勢。
- 新增動作：在 `js/poses.js` 的 `POSES` 加一筆（編號要對得上 `poses.md`），再到 `js/data.js` 的步驟指定 `icon`。`node tools/check-lessons.js` 會檢查編號與動作名稱是否相符。
- 圖示載入失敗時不顯示，課程照常進行。

### 改課程文字

課程文字有兩份：網頁用的 `js/data.js`，與文字版 `lessons/*.md`。改任何一邊，都要同步改另一邊，然後執行：

```bash
node tools/check-lessons.js
```

它會逐字比對標題、總時間、每一步的時間與口令稿，不一致就報錯。不需要安裝任何套件。

## 專案結構

| 路徑 | 內容 |
|---|---|
| [lessons/](lessons/) | 7 堂課的文字版。每堂有流程表與口令稿，檔案開頭的資料欄位（id、title、minutes、poses）方便之後轉成其他形式 |
| [poses.md](poses.md) | 動作庫：15 個動作的做法、停留時間、調整方式與來源 |
| [docs/research.md](docs/research.md) | 來源清單、動作篩選標準、被排除的動作與原因、研究證據、限制 |
| `index.html` | 網頁版的外殼 |
| `css/style.css` | 網頁版樣式 |
| `js/data.js` | 網頁版的課程內容、各動作的來源連結、說明頁小字、呼吸引導圈的秒數、朗讀的語速與句間停頓 |
| `js/poses.js` | 動作圖示產生器：從上方看躺在床上的人，用關節角度畫成簡單剪影（SVG） |
| `js/app.js` | 播放邏輯：倒數、呼吸引導、語音朗讀、暫停、下一步、背景切換時的時間補償、保持螢幕亮著 |
| `tools/check-lessons.js` | 比對 `js/data.js` 與 `lessons/*.md` 是否一致，並檢查每一步的動作圖示對得上 `poses.md` |

## 目前的限制

- 內容沒有經過瑜珈老師或物理治療師審閱，也沒有真人示範影像可以核對。
- 口令稿是依來源步驟改寫的原創文字。
- 網頁版只有課程 01，沒有影片。動作圖示目前只畫了攤屍式（P01）與仰臥束角式（P02），其餘動作還沒有圖示。
- 「保持螢幕亮著」、實機上的字體與亮度，只在模擬環境測過，還沒有在真正的手機上驗證。
- 語音朗讀用瀏覽器內建的語音，聲音好不好聽、手機上有沒有台灣國語語音，取決於裝置，我沒辦法預先確認。程式邏輯（挑語音、暫停、換步、失敗處理）用模擬的語音引擎測過。語速 0.85 與句間停 2.5 秒是自訂的規劃值。
